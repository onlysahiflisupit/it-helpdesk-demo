# Limits and release boundary

This is a public portfolio demo using fictional data.

| Area | Current limit | Before production |
|---|---|---|
| Identity | No login or role enforcement | Authenticate users and enforce permissions on the server |
| Storage | Data stays in a browser and can be cleared or edited | Database, backups, migrations and recovery checks |
| History | Client-side records are editable | Authoritative server audit trail |
| Privacy | Public fixtures only | Assess data collection, access and retention |
| Accessibility | Semantic controls and responsive CSS; limited checks | Keyboard and screen-reader review, contrast measurements |
| Compatibility | Browser automation scope documented separately | Safari/Firefox and real-device checks |
| Deployment | Local development server only | Hosted environment verification and security configuration |

Do not use real student, school, employer or client data here. A passing test suite does not make this demo production-ready.
